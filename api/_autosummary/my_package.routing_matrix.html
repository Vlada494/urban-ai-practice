my_package.routing_matrix.prepare_matrix_graph(graph)[source]

Align node IDs with CSR row order and keep the fastest parallel edge.

IduEdu 0.4.1 uses a nearest node’s ID directly as a CSR row number. IDs must therefore be 0..N-1 in iteration order, after component selection. Its MultiDiGraph conversion also keeps an arbitrary parallel edge, so choose the minimum time explicitly. Coordinates, direction and connectivity stay the same; the original graph and published Overture IDs are preserved.

my_package.routing_matrix.calculate_drive_matrix(blocks, graph, dtype=<class 'numpy.float32'>, max_workers=2)[source]

Calculate with BlocksNet, then add both straight-line approaches.

The old IduEdu helper adds approaches only when road time is positive. Add them explicitly here so different blocks sharing one road node also get their approach time. The same-block diagonal remains zero.
